# ARGON 4.0 // Native Android App (Kotlin + WebView + GitHub Actions APK Builder)

This repository contains the complete **Native Android App** for **Argon 4.0 (Gemini ZIP -> GitHub 1-by-1 Mobile Agent)**, designed to be built automatically in the cloud on GitHub without needing a laptop.

## How to Get Your Installable `.APK` on Mobile
1. Push all 20 files in this project to your GitHub repository (on the `main` branch).
2. GitHub Actions (`.github/workflows/build-android-apk.yml`) automatically starts building the Android app in the cloud.
3. Wait ~2 minutes, then open your repository's **Releases** section (`https://github.com/<your-username>/<your-repo>/releases`) on your phone.
4. Tap **`Argon-GitHub-Agent.apk`** to download and install the native Android app on your phone!
